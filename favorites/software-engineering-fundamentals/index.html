AI Engineering Skills Map: 软件工程基础

有了可代理化编程（agentic coding），软件工程基础发生了什么变化？即使所有代码都由 coding agent 来写，理解软件工程基础仍然很关键。它能帮助你给代理下达正确的指令，推动它做出你想要的权衡；更重要的是，你要知道有哪些权衡，甚至哪些权衡是你还没意识到的。

当你在构建 AI 应用时，AI 的核心通常是嵌入在更完整的软件应用里。你往往需要参与构建、组织和推动这个完整应用，而不仅仅是模型层。软件工程基础帮助你做到这点。

一个缺乏基础的“vibe coder”可能能写出看起来能跑的简单应用，但常常会被代理做出错误权衡：延迟、可用性、一致性、可靠性、可维护性、复杂性和成本之间怎么取舍。

如果你不知道有哪些 trade-off，实际上就无法用合适上下文去引导代理。因此，最终交付的结果通常偏离实际应用场景的要求。

这篇文章把这次 AI 工程调研里最重要的软件工程知识整理出来，核心包括：

  1. 构建全栈应用
  2. 数据管理
  3. 系统架构设计
  4. 系统安全与可靠性
  5. 生产环境扩展与运营

1. 构建全栈应用

Agentic coding 让很多以前偏前端、偏移动端的开发者，也能以更广的视角参与全栈。coding agent 的确可以补上你不熟悉的部分，但你仍要知道全栈是怎么运转的。

熟练的开发者要理解前后端系统的关键组成部分和核心概念，包括 UI 组件、缓存、页面渲染、API 的选型与设计、鉴权、状态与会话管理、异步处理、数据持久化、测试、安全性和可访问性。

2. 管理数据

数据很关键，因为软件都建立在数据之上，而且数据一旦设计不当，后期改动成本很高。

了解数据管理后，你才能根据访问模式（access patterns）选择应该存什么、存多久。你能判断合适的数据模型和存储类型（关系型、文档型、键值、图数据库），并选择对应的基础设施，直接影响速度、扩展性、可用性、可靠性和成本。

你要理解事务、并发，以及如何保持数据的准确、完整、持续更新。还要在需要时做好隐私、治理和合规。你还要管理数据生命周期。

随着应用迭代，你也要让数据架构同步演进。是否该改模型、改访问路径、改缓存方案，都是开发者要做的决策。AI 系统会从你的数据源拿输入上下文， 如果数据架构选错了，AI 就会“不知道它不知道什么”。这也是为什么软件工程能力必须跟 AI 能力一起出现：你得提供正确上下文。

如何给代理做数据基础设施，而不仅是传统人类或软件流程，仍在快速变化，要持续调整实践。

3. 设计系统架构

当你理解了全栈和数据的主要组成后，才更有能力组装成完整系统。好的架构设计先从“这个软件要做什么”开始：用户规模、延迟要求、成本约束、功能边界都要先清晰。

然后才是选择：前后端边界在哪，应用怎么拆分，状态该放哪里，架构要不要微服务化，单体是否更合适。你也会决定技术栈（语言、运行时、前后端框架、数据库和数据技术），有时还会通过实验对比后再敲定。

架构不是“一次性答案”。做 MVP 的架构和第一版生产架构通常不同，系统规模上来后又会变化。工程和产品背景都明确后，才能不断重构架构，做更符合当前阶段的权衡。

4. 打造安全可靠系统

可靠性离不开测试策略：单元测试和集成测试怎么搭配、用什么框架、覆盖率到什么程度。

你还要知道如何围绕故障设计系统：API 触发限流时该怎么降级、失败该怎样隔离、故障影响要如何收敛到最小区域。

现在安全也在“左移”：不是先把系统写完再补安全，而是把安全前置到流程里。像往常那样从前端到后端全栈都要上安全意识。

现在的开发者越来越多承担部分安全职责，也更常用 AI 工具扫描代码漏洞、查依赖供应链风险、审视云配置的攻击面。

但是，工具只能帮助你发现线索，真正做对安全决策仍需要工程基础。

5. 规模化与生产运维

要面对真实用户，必须把软件发布到生产环境。你要理解软件生命周期（SDLC）：不仅是编码和测试，还包括发布环境搭建、发布策略、CI/CD 自动化，以及基础设施服务（IaaS）的选型与配置。

生产运维要有可观测性体系，能配报警、能处理告警，能管理事故。

扩展能力要求你理解真实负载，并知道怎么扩容服务器、做负载均衡、怎样改造数据层（分片、索引、副本）或者调整架构应对增长。

长期看，版本控制、代码审查、依赖维护、技术债管理这些“工程习惯”才决定系统是否持续演进。

结语

Coding agents 改变了我们写软件的方式，甚至影响到非 AI 软件的开发方式。背诵语法、拼接常见模式这些能力在下降。

但真正理解软件本质的人，始终更有优势。

软件工程基础（加上 AI 工程能力）能帮助你更清楚地知道“软件能做什么、不能做什么”。这也会直接决定你如何使用 coding agent 和如何真正参与到产品建设中。后续我会继续展开说明。
